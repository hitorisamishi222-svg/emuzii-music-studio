# MUSIC-085 — 録音ピアノ6音色の強弱境界測定と補正前後A/B（2026-11-08）

## 実装したこと
- integration/recorded-piano-velocity-calibration.js：録音ピアノの弱音Vel01と強音Vel03の40〜300ms区間で短時間RMSを解析し、ベロシティ80→81切り替え時の推定音量段差をdBで計測。
- 既存6音色プリセットのみ補正を許可し、補正の適用範囲は±6dB以内、適用対象は強音の音量設定（region volumeDb）のみ。元の録音サンプル、スコアは一切書き換えない。
- tools/local-sampler.html に補正「なし／あり」の選択を追加。初期設定は「なし」。補正ありの場合はC3/C4/C5ごとに適用前・適用後の境界値を表示し、別名のWAVとして保存する。任意のSFZには自動補正しない。
- 元音源を複数オクターブに引き伸ばさないため、6音色プリセットの有効音域をMIDI 42〜78へ限定。範囲外は無理に再生せず、未割当ノートとして報告する。
- tests/recorded-piano-velocity-calibration.test.mjs と実録音を使う tests/real-piano-six-sample-browser.test.mjs で、補正上限・再現性・不正入力・補正前後の30秒WAV・末尾の無音2秒を検証。

## 実録音による測定結果
Meta Open SoundのピアノOGGプレビュー6件を、SHA-256で個別照合してからChromiumでデコード。

| 音域 | 補正前の80→81音量段差 | 強音側への補正 | 補正後の段差 |
| --- | ---: | ---: | ---: |
| C3 | +12.88 dB | -6 dB | +6.88 dB |
| C4 | +14.77 dB | -6 dB | +8.77 dB |
| C5 | +19.60 dB | -6 dB | +13.60 dB |

## 解釈と限界
- **3音域すべてで信号振幅の段差は6dB改善したが、残差が大きい。音のつながりが自然になったと断定しない。**
- この値は録音の40〜300ms区間における単純なRMS比較であり、人間の知覚ラウドネス、音色変化、アタック差、ピッチ・音長の自然さを保証しない。
- 上限6dB以上に補正を強めるより、**境界周辺で低・高ベロシティ録音を段階的にブレンドする手法**を次に検討する。位相干渉による音色変化、音量ピーク、処理負荷を測定し、耳でも確認する。
- 実楽器原本の48kHz/24bit版、各鍵の録音、スマホ実機、主観的なA/B聴感評価、配布製品の権利台帳承認は別工程。OGGはプレビュー用。
- 本番URL、main、既存SONG ID・TAKE・音源原本は変更なし。
