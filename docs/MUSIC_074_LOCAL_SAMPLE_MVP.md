# MUSIC-074 初期試作 — ローカルWAV楽器サンプルと単一region SFZ（2026-11-08）

## 目的
高額GPUや新規外部AI生成を使わず、手元の権利確認済みサンプルを音符データに割り当て、音程/強弱/長さで演奏する最小基盤を作る。30秒合成ガイド `integration/thirty-second-guide.js` の音符列を用い、合成音から実サンプルへの置換を可能にする。

## 追加した開発版
- `integration/local-sample-sampler.js` — 1～2ch Float32Array音源をリニア補間で再標本化し、MIDI音程・ベロシティ・アタック/リリースの音量変化を加える。未使用サンプルを変形しない。末尾で勝手にループしない。音が短ければ音符の途中で終了する。
- `parseSingleRegionSfz()` — **<region>を1つだけ**持つSFZの一部オペコード（sample、key、lokey/hikey、pitch_keycenter、lovel/hivel、volume、ampeg_attack/release）のみ解析し、未知・重複オペコードを拒否。sampleは同じ画面でユーザーが選択する単一の安全なWAVファイル名に限定。パス/外部URL/自動ダウンロードは禁止。
- `tools/local-sampler.html` — お手元WAVと任意SFZを選び、使用権限を自分で確認した後、30秒ガイド（または1音）をローカル演奏。WAVとして書き出し、最後の2秒はゼロPCM。出力ピークが1を超えれば音割れの危険として書き出し拒否。原本ファイルは非破壊。
- `tests/local-sample-sampler.test.mjs` — ピッチ・音量・リージョン境界・出力WAV・元音源保護・未知SFZオペコード拒否を単体検査。
- `tests/local-sampler-browser.test.mjs` — ブラウザ上で合成したテスト用WAVをアップロードして、30秒ガイドとSFZ単音を再生・保存する工程を検証。
- 外部API、サンプル配信、GPU課金は使用しない。テスト用素材はプログラムで生成した**架空の合成音**で、実楽器品質の証明ではない。

## 使い方（開発ブランチをWebサーバーで表示できる場合）
1. `tools/local-sampler.html` を開く（JavaScriptのES moduleのため、通常はローカルHTTPサーバー等から表示）。
2. 自分が使用権限を確認済みの単音WAVを選択。基準MIDIノート（中央ド=60、A4=69）を設定。
3. 必要に応じて対応SFZ `<region> sample=harp.wav pitch_keycenter=60 ampeg_attack=0.02` を選ぶ（WAVも `harp.wav` を選ぶ）。
4. 画面の「使用権限を確認済み」にチェックし、30秒ガイドのWAVを作る。生成音の強弱/音程/ノート切れを**必ず試聴**。
5. SFZが1つのサンプルしか指定しないため、キーや音域によってはガイドの音符がスキップされる。複数リージョンやベロシティレイヤーは今後の課題。

## 制限と今後
- **現時点でSF2は未対応**。ほとんどの実SFZ音色は複数リージョン/サンプルを含むため、この試作は一般的なSFZファイルを正しく再生できると主張しない。
- ピッチ変更は再生速度に影響するため、オクターブ移動するとサンプルの長さ・音色も変化。位相ボコーダーや高品質再標本化は未実装。
- サンプル自身の品質、録音環境、余韻、ループ点、権利ライセンスは未検証。個人でのプレビュー許可にチェックしただけでは商用利用権限やサンプル再配布権限は成立しない。
- WEB UIは開発ブランチのみ。iPhone/Androidの実機未検証。本番サイトへの統合・公開なし。
- 次工程：ライセンス確認できた実楽器サンプル1件で単音実聴→マルチサンプル・複数SFZ region→複数の音源でのアレンジ→演奏表現。
