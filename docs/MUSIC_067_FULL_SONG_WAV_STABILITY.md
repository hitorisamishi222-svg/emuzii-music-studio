# MUSIC-067 — 3分34秒のフル尺WAVで音量・継ぎ目・休符を実ブラウザ検証

## 背景
MUSIC-066では33秒・7チャンクの実Chromium WAV検証に成功したが、実際の楽曲として多い3分以上の出力で最後まで音量が維持できるか、書き出し時間・WAVフレーム数・再生後半の継ぎ目まで検査できていなかった。

## 今回の追加
- `tests/master-multitrack-browser.test.mjs` に、**3分34秒（214秒）**のハミングガイドをChromiumの本物の`OfflineAudioContext`から書き出すMUSIC-067ケースを追加。合成テスト音源のみを用い、ユーザーの原音は用いない。
- 21組の3音フレーズ（63音）と、1.2秒の同音ロングトーン5本、75msの短音3本を並べた楽曲を再現する。
- iPhone互換WAVの**5秒単位・43チャンク**を通して44.1kHz/16bit/stereo WAVを書き出し、長さ214秒がサンプル数・RIFFヘッダと一致することを確認する。
- 冒頭・中盤・終盤の同一ロングトーンのRMS、5秒/100秒/200秒をまたぐ極短音の前後RMS、3箇所のフレーズ、5箇所の休符、全尺のピークをチェックする。
- 99%付近のデジタルクリップを避けられているかを定期サンプリングで確認。ブラウザ例外、WAV出力UIの進捗100%、外部有料生成APIへのリクエストゼロも検証する。

## 合格基準と留意事項
- 安定性の数値基準は既存のMUSIC-066と整合させ、ロングトーンの最大/最小RMS比が1.45未満、短音継ぎ目は2.8倍以内、休符は0.0005未満であることを求める。
- 数値・WAVの実レンダリングテストであって、実ユーザー歌唱のフル尺聴感評価や、iOS/Android実機検証を済ませたことを意味しない。
- 元録音、MIDI、保存データ、楽曲ID、既存本番URL/mainは変更しない。有料GPU・新規プロジェクト作成・本番デプロイは行わない。
