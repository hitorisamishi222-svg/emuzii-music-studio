# MUSIC-043 — ハミング風ガイドのレガート連結

## 改善内容
従来のハミング風も音符ごとにWeb Audioの発音を個別に停止・開始しており、近接する音符の間に小さな無音が発生した。ハミング風音色を選択した場合に限り、前音の終端と次音の開始が80ms以内なら、前音を次音開始の18ms後まで一時的に延長する。これにより短い区切りをつなげ、次音と控えめにクロスフェードさせる。

- 処理は `hummingLegatoNotes` が作る一時オブジェクトにだけ適用する。`track.notes` の原本、MIDI書き出しの時刻、SONG ID、原音Blob、保存DBを一切変えない。
- 長い休符（80ms超）、ドラムとの境界、不正な音符、もともと重複している音符はそのまま維持。
- ピアノほか従来音色とデフォルトのエレクトーンには一切適用しない。
- 通常のトラック試聴と`buildChunk`を使うガイド合成で同じ処理を使う。
- 4音の「音色を試聴」ボタンも、実ガイドと同じ`scheduleGuide`経由のレンダリングへ変更。

## 検証
- 合成単体契約試験で短ギャップ・休符・先行重複・原本不変・従来音色の不変を照合。
- 実Chromiumでプレビューを再生し、C4音符の停止時刻がD4音符の開始時刻を少し超えることを確認。
- 歌入れ橋渡し、保存破損への対応、実ブラウザの多トラックMASTER WAV回帰がPASS。
- https://github.com/hitorisamishi222-svg/emuzii-music-studio/actions/runs/41810954819

## 評価範囲
実ブラウザにおける音の重なりを確認したものであり、ユーザーが求める「本物の鼻歌に近い聴感」を保証するものではない。また、メインの`renderMasterMix`は別のガイド音符レンダラーを使うため、本変更のレガートがMASTER WAVにも適用されたとは宣言しない。iPhone・Android実機、元歌唱の音色再現、実GPU・本番公開も未検証。公開URL・`main`は未変更。
