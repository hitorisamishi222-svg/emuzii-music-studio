# MUSIC-064 — フレーズ抑揚の5秒・10秒WAV分割連続性

## 背景と検出した問題
MUSIC-063の `hummingPhraseGain` は元の楽譜全体から決定論的に計算されるため、分割書き出しでもフレーズ内の各音符の強弱係数は同じだった。一方、MUSIC-057/062の元音符時刻に基づく振幅エンベロープは、0.65秒以上の音符、または所定の短いポルタメント音符に限られていた。分割境界をまたぐ同音反復など0.28〜0.65秒のハミング音は、分割区間の先頭と末尾で誤った再アタック・リリースを受ける可能性があった。

## 修正
- `app-v10.3.2.html` の `scheduleTone()` において、ハミング音符の元音符相対エンベロープを **0.28秒以上すべて** に適用し、`glideFromMidi` の有無に依存しないよう変更。
- 既存の `MUSIC-063` フレーズ係数、`MUSIC-058/059` 振動の位相連続、`MUSIC-062` 45msポルタメントを保持。元音源・MIDI・保存データ・本番mainやURLは変更しない。
- 0.28秒未満の非常に短いハミング音およびハミング以外の音色は従来の挙動のまま。ごく短音の分割境界の品質は今回の保証対象外。

## 検証
- `tests/master-multitrack-contract.test.mjs`：5秒/10秒を横切る同音3音のフレーズ係数がフル尺・分割区間で同一となること、スライド無しの0.34秒ハミングが元音符位置による音量エンベロープを維持し、チャンク左右端の音量が一致することを数値で検証。
- 数分尺の模擬630音符・70フレーズで冒頭/中央/末尾の強弱が一貫し、原音符を変更しないことを検証。
- `tests/master-multitrack-browser.test.mjs`：13秒・44.1kHzの実Chromium互換WAVで、5秒と10秒の両境界にかかる同音3音フレーズを出力。各フレーズの中央音符の控えめな強調、再生長、長い休符・末尾の無音、外部生成APIを使わないことを確認。
- 従来のハミング持続音、繰り返し発音、他楽器、MASTER、Vocal Bridge、プロジェクト保存と復元の回帰テストを実行。
