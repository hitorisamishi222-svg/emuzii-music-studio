# MUSIC-026 — 手動編集トラック削除の取り消し（2026-11-03）

## 背景
従来はトラックの「削除」ボタンで即座に配列から消え、その後自動保存された。誤操作の救済がなく、元の録音が削除されたプロジェクトを上書きする可能性があった。

## 実装
- 編集画面に「トラック削除を取り消す」ボタンを追加。取り消しは削除順のスタック（最新10件）で保持。元のトラックID・音声Blob・位置・音量・フェードなどのトラックオブジェクトを元の順序へ戻す。
- 歌の別プロジェクトを読込・ローカル作曲を新規生成した場合はスタックを消去し、異なる作品のトラックを混ぜない。
- 取り消しは同じブラウザセッションのメモリ上のみ。ページ再読込後には使えないとUIに明記する。削除前の内容が復元可能なことを誇張しない。
- 開発ブランチのみ。保存データのスキーマ・本番・既存のオリジナル音声には手を加えない。

## 自動検査
`tests/master-multitrack-browser.test.mjs` に既存合成2トラック（伴奏・ボーカル）のうち先頭トラックを削除し、UndoでID/順序・2トラックを再確立する操作を追加。既存完成WAV、保存・復元、歌入れ連携テストへの影響も確認。
