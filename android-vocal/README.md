# ASAHI 歌入れサポート Androidアプリ（試作・v0.18）

Androidは専用WebViewアプリ、iPhoneは独立Web版。アプリにはネット接続不要の録音UIを同梱し、同じ機能・TAKE形式を共有します。

## 機能
- 端末内MP3/WAV読み込み、伴奏を聴きながらマイク録音
- 歌声原音・ミックスWAV・SONG ID/TAKEデータを記録
- ±3.00秒、0.05秒刻みのタイミング補正
- 曲の途中から録音する開始位置（0〜7200秒、0.05秒刻み）を保存・復元・WAV合成へ反映
- `.asahiproj` で伴奏・歌声・SONG ID・補正値・開始位置を総合ミュージックと双方向に受け渡し
- IndexedDBへの自動保存、.asahitakeバックアップ、.asahiprojプロジェクト保存
- 長時間録音は約1秒ごとの音声断片を端末内へ途中保存し、正常停止時に再構成
- アプリ終了・画面切替などで録音が中断した場合、保存済み断片から前回録音を自動復旧
- ブラウザ保存領域が利用できない場合は録音自体を止めず、メモリ録音へ自動退避
- 「端末診断を実行」ボタンでマイクAPI・Web Audio・MediaRecorder形式・IndexedDB・録音断片の読み書き・保存容量を確認
- 診断結果をJSONで書き出し。録音断片テストの仮データは終了時に削除
- 「再起動復旧テスト」でテスト用WAVを分割保存→ページ再読込→自動復旧→WAVデコード→TAKE保存→メタデータ検査→テストデータ削除まで一括検証
- 再起動復旧テストは本物のTAKEや伴奏を読み込んでいる時は実行不可にし、既存録音への誤操作を防止
- 「実マイク5秒テスト」で実際のマイクを5秒だけ録音し、MediaRecorder完了・録音サイズ・デコード・録音時間・ピーク/平均音量・声の検出を自動確認
- マイクテストは通常TAKEへ保存せず、専用の一時録音セッションを使用。端末内チャンク保存が使える場合は同時に確認し、終了後に一時データを削除
- 「3分耐久録音テスト」で3分間の実マイク録音、1秒単位チャンク、途中保存失敗回数、再結合、再デコード、保存容量差、途中停止理由を確認
- 耐久テストは通常TAKEへ保存せず専用一時セッションを使用し、完了後に一時データを削除
- 画面オフ・別アプリ移動時は耐久テストを安全停止し、正常完走と途中停止を区別して結果表示
- イヤホン/端末ごとの実音ズレ、3分を超える長時間、OSがアプリ自体を強制終了した場合の挙動は別途実機確認が必要
- Android保存先選択に対応した大きなファイルの分割転送

## アプリの安全対策
- WebViewAssetLoaderでローカルHTMLをHTTPSオリジンとして提供
- マイクだけをユーザー許可後に利用。カメラ・画面キャプチャは不許可
- 外部ドメインへのWebView遷移は拒否。Web側データはサーバーへ自動送信しない
- ユーザー指定の保存先にのみWAV等を書き込む。アプリ内保存は端末データ消去で失われる可能性あり

## ビルド
GitHub Actionsの `Build Android Vocal APK` でデバッグAPKをビルドする構成。Android Studioで開く場合は `android-vocal` ディレクトリを開いてください。

**状況**：GitHubの開発ブランチにv0.18ソースを保存し、GitHub ActionsでデバッグAPKのビルド成功を確認。APK内部にv0.18の録音画面が含まれることも確認済み。iPhone・Android実機での長時間録音、強制終了後の復旧、APKインストールは未検証。署名済み配布版やPlayストア公開版ではありません。

`android-vocal/app/build.gradle` がルートの `vocal/index.html` をビルド時にアプリ内へコピーします。Web版とアプリ版の画面ソースは共通です。
