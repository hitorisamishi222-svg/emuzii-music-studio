# ASAHI MUSIC SYSTEM — 確定した独自音源・演奏エンジン方針（2026-11-08）

## 基本目的
Sunoへの依存・生成回数・ダウンロード回数を減らし、無料または低予算の自前音源・アサヒの作曲設計・ユーザー主体の手動編集を組み合わせ、高品質で独自性のある音楽を作る。元の完成音源を上書きせず、再現できる演奏情報・音源台帳・編集履歴を保存する。

## 確定した開発順序
1. **多楽器音源**：世界各国の実楽器、和楽器、自然音、特殊音の音源を探し、SoundFont（SF2）・SFZなどの利用可能な方式で取り込める基盤を整える。独立した音色ライブラリは音源本体とメタデータを分けて管理。
2. **実楽器サンプル品質**：単一のループ音色だけでなく、打鍵・弓・管・撥弦等の音量差、複数ベロシティ、アタック/リリース、ラウンドロビンや自然な残響のある合法的サンプルを段階的に導入。第1段階と並行して品質確認する。
3. **演奏表現**：音の長さ・発音の早遅・ヒューマナイズ・強弱・息遣い・余韻・アーティキュレーション（レガート、スタッカート等）を演奏パラメータとして記録できるようにし、再生のたびに同じ結果を再現できる。
4. **複数曲／演奏融合**：独立して作った2曲以上の旋律、対旋律、リズム、和声や自然音をテンポ・調性・拍の単位で整列/融合。単に「3曲の雰囲気をプロンプトへ混ぜる」方式と、複数の実際の演奏パートを重ねる方式を区別する。
5. **歌唱統合**：歌唱音声、伴奏、発音/歌詞タイミングを非破壊で調整し、表現豊かな歌声と組み合わせる。将来の自動歌唱は品質・権利・費用が確定してから接続する。

## 最初の実装スコープ
- SFZ/SF2対応の可否調査および実装方式・許諾条件の棚卸し。ライブラリ自体の互換性を確かめず「演奏できる」と報告しない。
- 音源メタデータ台帳：由来URL、ライセンス原文/リンク、確認日/確認担当、用途（個人制作・商用完成曲・サンプル再配布）ごとの許可を**個別**に持つ。
- 権利確認が不明・未検証の場合、音源本体のアプリ同梱／公開配布／制作ワークフローへの自動登録はしない。完了した演奏音声の公開許可と、音源サンプル自体の再配布許可を同一視しない。
- 自然音のみの作品と、自然音に通常の楽器を混ぜた作品を明確に分類し、楽曲レシピで再現可能にする。
- 既存Web Audio、WAVレンダリング、MIDI、トラック・保存形式を保護しながら、別モジュールとして追加してから既存UIに段階統合する。

## サンプル調達時の確認（必須）
1. 公式または正規配布元から出典・名称・権利者・ライセンス本文を保存。
2. 商用利用・改変/ピッチ変更・作品配信・クレジット・サンプル再配布の可否をそれぞれ確認。
3. ダウンロード/解凍時は音源本体だけでなく付属ライセンス情報・帰属表示を失わない。
4. 許諾範囲が不明なら使用/配布を「要確認」に維持し、合格扱いしない。機械検査は記録の存在と条件整合のみ確認し、法的な正しさは人が確認する。
5. 無償でも「非商用のみ」なら事業の商用完成曲へ自動採用しない。

## 受入段階・誤認防止
- **設計**：台帳フォーマット・境界・テストのみ。実楽器の音は未提供、実音色は未検証。
- **取り込み試作**：権利確認済みの手元の音源を読み込み、1音以上を発音し、WAVに変換できる。
- **演奏エンジン試作**：同じ音を異なる強弱・奏法・タイミングでレンダリングし、数値比較と実聴をする。
- **制作統合**：楽曲2本以上の独立パートから新しいアレンジを作り、ステム・音源・編集履歴を保持する。
- **歌唱統合**：歌詞照合、歌声/伴奏の音量/音域、アウトロ確認まで試験。
