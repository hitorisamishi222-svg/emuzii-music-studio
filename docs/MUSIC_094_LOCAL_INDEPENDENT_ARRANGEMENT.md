# MUSIC-094 — 独立した2曲の音符をローカル楽器で演奏し、ステレオWAVに融合

2026-11-09。既存の開発ブランチ `feature/vocal-recorder-v1` のみ。公開中の本番環境と音源原本は不変更。

## 実装
`integration/independent-arrangement-renderer.js` で、MUSIC-093の拍グリッド配置、既存のローカルサンプラー、MUSIC-092のステレオステム合成を一続きに接続した。

1. BPM・拍子が異なる独立した楽曲の音符を、指定した共通BPM・拍子に非破壊で配置する。
2. 各楽曲にローカルのデコード済みサンプルと音域・ルート音・音量・定位を指定し、別々のモノラル演奏PCMを生成。
3. 全音符がサンプル音域に入り、録音の長さが足り、クリップしていないことを確認。不正な条件ではWAVを出力しない。
4. 2本以上の演奏PCMを左右定位・ヘッドルームつきで合成し、2秒の完全無音を末尾に追加した16bitステレオWAVを書き出す。

## テスト結果
- 3/4・90 BPMの旋律と4/4・140 BPMのベースを、120 BPM・4/4の拍グリッドへ配置。
- 2種類のローカル合成サンプル（正弦波の減衰を用いた**テスト専用の疑似楽器**）で、実際のステレオWAVを作成。
- WAVヘッダー、左右差、末尾無音、元の音符・サンプルの不変性、同じ入力の再現性を検証。
- 音域外・短すぎるサンプル・演奏時間不足・過負荷・楽器数不一致を拒否。
- CI: https://github.com/hitorisamishi222-svg/emuzii-music-studio/actions/runs/42631279498 （成功）
