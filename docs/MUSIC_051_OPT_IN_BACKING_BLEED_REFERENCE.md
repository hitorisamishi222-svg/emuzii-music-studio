# MUSIC-051 — 選択式の伴奏漏れ参照音源補正

## 目的と範囲
マイクで歌入れした歌声に再生中の伴奏が混入すると、単音の基本周波数ではなく伴奏側の低音や繰り返し周期がメロディとして誤検出される恐れがある。既存の音程解析・元録音・アレンジ・ガイドMIDIは維持し、**利用者が任意で有効にできる一時的な伴奏漏れ減算**を追加した。

## 実装
- ガイドメロディ欄に`guideBackingReference`チェックボックスを新設。**初期状態はオフ**。オンで現在のプロジェクトに`type:"backing"`の参照音声トラックがある場合だけ処理を試みる。参照がない場合、補正なしで通常の音程解析を継続。
- ボーカルと参照伴奏を`OfflineAudioContext`で12kHzへ変換。トラック開始時刻の差を考慮し、さらにマイクやモニター由来のズレを±100ms範囲で探索。粗いサンプル間隔では周期的な伴奏の別の相関ピークへ誤整列したため、候補探索6サンプル、最終調整1サンプルへ高精度化。
- 全曲に比例して遅くなりすぎないよう、相関評価するPCMのサンプリング間引きを上限約12,000点に制限。十分な重なり、相関係数0.3以上、正の混入ゲイン0.025～0.9未満を満たす場合だけ、元の歌声配列を**コピーしてから**参照伴奏の推定混入分を減算。最大実適用ゲイン0.85。
- ボーカル・伴奏の元PCM、Blob、保存済みノート、プロジェクト情報は書き換えない。オン/オフは抽出時の操作であり、新規に生成したガイドだけに結果を反映する。
- 歌声と伴奏が不整合・相関不足なら「伴奏補正なし」の状態を通知する。

## 検証
- 単体試験：4秒の人工声と110Hz/196Hz/137Hz等の複合伴奏を合成し、25msの遅延と37%の漏れを付加。探索した遅延が真値の±8サンプル以内、参照後の残留誤差エネルギーは減算前の8%未満、元の両PCMが変更されないことを確認。
- 安全性：関連のない伴奏、参照音源なしの場合は歌声の`Float32Array`への参照がそのまま返り、勝手な補正が働かない。
- 実Chromium：22秒の倍音・ビブラート・疑似子音・息を含む12音の歌声と25ms遅延混入の参照伴奏をそれぞれ個別WAVとして画面に読み込み、任意チェックをオンにして「ガイドにする」を実行。正解の`C4 D4 E4 G4 C5 A4 A5 E5 C5 A3 C4 A4`を12音完全一致で取得。元の歌声・伴奏トラックが両方残っていること、外部有料APIを呼んでいないことも検査。
- 195.22秒の曲末尾100ms音符、子音ノイズ、MASTER、WAV分割、録音/保存・復元の回帰試験もすべてPASS。
- CI：https://github.com/hitorisamishi222-svg/emuzii-music-studio/actions/runs/41947403017

## 制限
**伴奏分離AIではない**。録音時の伴奏が現在の参照伴奏に相関していることが必要。マイク・スピーカー由来の反響、時間変動する遅延、ピッチの変更、収録前のEQ/コンプレッサー処理、他の音源の混入や大きく異なるテンポは補正対象外の場合がある。強い歌声との相関が偶然生じるケースも残るため、初期状態はオフとし、利用者が必要時だけ有効化する。実ユーザーの歌唱録音と本番の耳による評価、iPhone/Android実機、共通エンジン・GPU・本番公開の4ブロッカーは引き続き未検証。
