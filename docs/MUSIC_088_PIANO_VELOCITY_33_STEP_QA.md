# MUSIC-086 / MUSIC-088 — ピアノ6録音・強弱64〜96の33段階連続監査（2026-11-09 JST）

## 技術成果
以前の境界80→81だけでなく、**ベロシティ64〜96の連続33段階**をC3/C4/C5それぞれの元の録音基準音で検証した。3音域の合計99個の異なる強弱設定を実際の録音サンプルからWAV化。信号レベルの音量逆戻りを自動監査し、1つのブレンド方式に「必要な箇所だけ減衰する」補正を追加した。

## 実装と検査
- `integration/piano-velocity-sweep-audit.js`: 33段階の検証音符と、各音符50〜300msのRMS / dBFS / 最大振幅 / 隣接ベロシティ差 / 逆戻り箇所を計算。逆戻りの検出基準は **隣接差が-0.25dBより小さい場合**。レベル測定は知覚ラウドネスや音色の評価ではない。
- `integration/recorded-piano-velocity-blend.js`: `planRecordedPianoLevelGuard` を追加。元録音の40〜300ms区間RMSと波形相関からブレンド後の音量曲線を見積もり、強音側から順に必要なベロシティの振幅だけを減衰させる。**増幅しない・最大減衰6dBまで・過度の打ち消しなら拒否**。元音声/元スコアは不変。
- `renderRecordedPianoVelocityBlend(...,{levelGuard:true})` が新しい補正モード。既存の補正なしブレンドを変更せず比較可能。
- `tools/local-sampler.html`: 第4の選択肢「ブレンド＋音量逆戻り抑制」を追加。標準は従来通り補正なし。補正の対象段階と最大減衰量を表示し、別名でWAVを保存。
- `tests/piano-velocity-sweep-audit.test.mjs` / `tests/recorded-piano-level-guard.test.mjs`: 連続測定・異常なPCM・検出・最大ゲイン・元音源保護・サンプル不足をテスト。
- `tests/real-piano-six-sample-browser.test.mjs`: CC0録音6件を個別SHA-256で確認してから、ChromiumでC3/C4/C5のそれぞれ33音を演奏し、補正前・補正後のWAVと監査データを記録。さらに30秒ガイド4方式（原録音/音量補正/ブレンド/ブレンド＋逆戻り抑制）を作成。
