# MUSIC-028 — トラック名の安全な手動変更

手動編集の整理を改善するため、「名前変更」ボタンを追加。インラインで名前を編集し、Enterで確定、Escapeでキャンセル、空名は拒否。変更時は既存の`track.name`だけを更新し、`track.id`・音源Blob・SONG ID・TAKE・フェード等を変更しない。通常の自動保存を実行する。

合成WAVを読み込んだ実Chromiumで、Unicode/絵文字を含む名前に変更→保存→ページ再読込→復元して同じ名前と元のトラックIDを確認する。内部のHTML挿入には既存のtextContentを利用し、直接HTMLとして曲名を埋め込まない。

開発ブランチのみ。本番・既存楽曲・Android実機には手を加えない。
