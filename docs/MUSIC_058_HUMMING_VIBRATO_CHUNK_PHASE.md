# MUSIC-058 — 長音ハミングのビブラート位相・深さをチャンク間で維持

## 問題
従来のハミング音色は、`scheduleTone()` が独立した5秒・10秒WAVチャンクを描画する際、ビブラートを毎チャンクの初頭で作り直していた。特に `voicedSeconds=stop-start`（そのチャンクで聴こえる長さ）に応じてビブラートの有無が切り替わり、短い断片では本来続いている揺れが消えていた。

## MUSIC-058 変更
- 元の音符長 `note.duration` を参照し、0.28秒以上のハミングではチャンク末尾が短くてもLFOを継続。短い本物の音符は引き続きビブラートなし。
- 強さは元音符の開始からの経過秒数で決定。0.14〜0.26秒の導入フェードを、チャンク境界後でも0からやり直さず、途中の強さから再開する。
- Web Audio `PeriodicWave` を使い、開始し直したLFOの波形の初期位相を元音符の開始位置に合わせる。角度は `2π × (音符開始からの経過秒 × LFO周波数 mod 1)`。フーリエ係数 `real[1]=sin(角度)`, `imag[1]=cos(角度)`, `disableNormalization:true` で、合成結果を従来の正弦波と同じ振幅にする。
- 元の音符の先頭から再生する場合は従来の正弦波を使用。Web Audioの PeriodicWave が使えない環境ではエラーを起こさず従来の位相で再生できるが、境界位相の完全一致は保証できない。
- 一般ガイド音色（ピアノ等）のLFO、合成ハミングの5倍音、MUSIC-045/056/057のクロスフェード・共鳴・音量処理は維持。
- 原音・保存データ・MIDI・声・本番 main・本番公開URL を変更しない。外部GPUは不要。

Web Audio仕様参照: https://www.w3.org/TR/webaudio/ （PeriodicWave real/imag の Fourier 係数定義）。

## 自動検査
- `tests/master-multitrack-contract.test.mjs`：7秒持続音を5秒・10秒の模擬区間に分割し、LFOの初期位相と元の長音の位相が一致すること、位相回転による振幅が1に保たれること、短く切られた長音にもLFOが維持されること、途中からのフェードイン深さの持続を確認。
- `tests/master-multitrack-browser.test.mjs`：13秒の合成ガイドをChromiumのOfflineAudioContextで実際にWAV化し、両チャンクで `createPeriodicWave` が呼び出され、係数が有界で位相補正が非ゼロであることを検証。既存の44.1kHz、音量、休符、末尾音のテストも保持。
