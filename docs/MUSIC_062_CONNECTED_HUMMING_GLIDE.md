# MUSIC-062 — 小さな音程移動のハミング専用ポルタメント

## 背景
MUSIC-061では繰り返し音符・大きな跳躍のブレスを保護したが、つながった小さな音程移動は別々の固定音程オシレーターで始まり、短い音程ジャンプが機械的になる可能性が残った。

## 開発版の変更
- ガイド音色がハミングの場合のみ、元音符と直前音符の差が1〜5半音、両者の隙間が0〜50msの場合、再生時だけ次の音符に `glideFromMidi` を与える。
- 音色試聴ボタンではハミングの場合だけ2回の微小な接続を設け、最後の自然なブレスは維持。ほかの楽器の試聴フレーズは変えない。
- 次音符の発音冒頭に最大45msの指数周波数スライドを付ける。5本のハミング倍音すべてに周波数比を維持して適用する。
- 同音の再アタック、6半音以上の跳躍、50msを超えるブレス、既に重なっている音符にはスライドをつけない。
- MUSIC-058/059の分割境界の位相引き継ぎを保持。指数周波数の積分を用い、5秒・10秒のWAV分割でスライド途中に入っても開始位相・開始周波数・残りスライドを元音符基準で復元する。
- 短いスライド付き音符の分割境界も音量エンベロープを元音符基準にし、区間終端がアタックや減衰途中でも途中の正しい音量までオートメーションを確定する。
- 保存済みのMIDI、原録音・音声Blob、プロジェクト構造、SONG ID、音量調整、他のガイド音色、公開mainや本番URLは変更しない。

## 開発検証
- `tests/master-multitrack-contract.test.mjs`：小さな音程移動の一時スライド付与、同音・跳躍・ブレス除外、元音符非破壊、5倍音周波数ランプと最大45ms、分割WAV途中の周波数・位相積分一致、短音音量エンベロープの切り出し連続性。
- `tests/master-multitrack-browser.test.mjs`：Chrome/Chromium WebAudioの実音色試聴でC4→D4の周波数ランプ、微小オーバーラップ、実音声WAV書出しと既存回帰を検証。

## 限界と留保
合成ハミングの小さな音程遷移だけの改善であり、人間の歌声そのものへの変換ではない。フル尺の実歌唱聴感、iOS/Android実機、GPU費用が必要な生成、公開は別工程でありこのタスクでは実施しない。MUSIC-040/050/060/070の保留は継続。
