# MUSIC-034 — 端末内に保存した曲構成名はテキストとして安全に表示

2026-11-03 / 開発ブランチのみ。

これまで曲構成の描画は`innerHTML`へ名前を直接挿入していた。保存済みデータの読み込みを拡張する際、文字列内にHTML形式の文字が含まれてもコードとして実行されないようにする必要がある。

`renderSongForm`をDOM生成の`textContent`と`createTextNode`に変更。曲構成の時刻/密度表示と見た目を維持し、名称がHTML形式の文字を含んでも装飾や画像タグに変換しない。

CIでは合成プロジェクトにタグ風のセクション名を入れて読み込み、要素が生成されず文字として表示されることをChromiumで検査する。本番には変更しない。
