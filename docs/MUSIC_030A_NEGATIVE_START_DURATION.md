# MUSIC-030A — 負の音声開始位置を曲尺表示へ正しく反映する

2026-11-03 開発ブランチのみ。MUSIC-020の個別改善。

編集画面では録音の音ズレ修正で開始位置をマイナス値にすることができる。通常再生と完成WAVでは「開始位置＋音源長」で可聴区間が計算される一方、`maxDuration()` は `max(0,開始位置)+音源長` としていたため、例えば1.3秒の音声を -0.5秒ずらしても表示尺が1.3秒のままだった。正しい表示は0.8秒。

`maxDuration()` をクリップ開始位置と音源長の合計を0以上に制限する計算へ変更。負開始時の余分な余白を除く。通常の正開始・MIX出力・ガイド音符処理・音源Blobには変更を加えない。

単体テストは負開始(-0.5s)、正開始(+0.3s)、複数トラックを確認。Chromiumでは読み込んだ1.3秒音源を-0.5秒へ変更すると長さ表示が0.8秒、0秒へ戻すと1.3秒になることを確認する。
