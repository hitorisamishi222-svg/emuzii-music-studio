# MUSIC-035 — 音源付き作品のオフライン持ち運び（2026-11-03）

## ユーザー操作
MUSIC STUDIOの「保存」→「音源付き作品バックアップを保存」で `.asahi-music` 形式の1ファイルを作成。歌声・伴奏などの元音源バイト列、トラックID・時間補正・手動編集メロディ/コード/曲構成、曲設計を含む。

「音源付きバックアップを読込」でファイルを選び、全てのデータの整合性検査後に確認して読み込む。ユーザーが明示的に「編集状態を保存」するまでは、取り込んだ作品を端末内保存レコードへ自動上書きしない。

## 破損検出と互換性
- `integration/portable-music-backup.js` のV1専用バイナリ形式。MAGIC + ヘッダ長 + ヘッダCRC32 + JSONマニフェスト + 元音声Blob列。音声単位にサイズとCRC32を記録。音源を変更したり外部サーバーへ送信しない。
- ファイルを復元する前に、MAGIC/スキーマ/トラック参照/サイズ/管理情報CRC/各音源CRC/末尾の余剰バイトを検査。不一致なら今の作品を変更しない。
- バックアップ取り込みは既存 `restoreProjectRecord` の非破壊検査を利用し、破損音声を音源として採用しない。
- `MUSIC-035`はMUSIC STUDIOの**作品データと元の音声**の持ち運び。レポート/内部診断履歴など全てのアプリ状態まで無条件に保存するものではない。
- CRC32は誤破損検出用で暗号署名ではない。出力ファイルには本人の歌声が含まれるため共有範囲に注意。

## 検証
`tests/portable-music-backup.test.mjs`は音声バイト一致・編集情報一致・破損拒否などをオフライン検証。
`tests/master-multitrack-browser.test.mjs`は実Chromiumで2音声のファイル作成、破損ファイル拒否、正常読込、端末保存・再読込を確認。 Android実機テストや本番反映とは別。
