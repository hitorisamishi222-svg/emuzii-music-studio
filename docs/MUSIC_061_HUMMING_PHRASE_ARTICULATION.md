# MUSIC-061 — ハミングの歌い直し・跳躍のフレーズ分離

## 課題
従来の `hummingLegatoNotes()` は、80ms以下の隙間を音程差と無関係に全て延長していた。同一音を二度歌うときの短い無音や、大きく音程が跳ぶ直前の息継ぎまで埋めることがあり、合成ガイドが一続きの機械音に聞こえる原因になり得た。

## 開発ブランチのみの改善
- 音符間の隙間が80ms以下のときにも、同一MIDI音高の繰返しなら先行音符を延長せず、次の音のアタックを独立させる。
- 7半音以上の大きな跳躍で26ms以上の間があるなら、ブレスや音の切り替えを明瞭にするため延長しない。
- 異なる音程での小さな移動や、25ms以下の非常に接近した跳躍は、従来の短いレガート延長を維持。
- 明確な80ms超の休止、重なり済み音、ドラム、非数値ノートの安全動作は変更しない。
- このロジックはハミングガイドの再生用コピーにだけ適用し、保存された音符の開始位置・長さ・音高、MIDI、録音原本、他音色、バックアップデータは不変。
- MASTERガイドの明示ONと既存のStudio/Vocal連携契約は維持。GPUや有料APIは使わない。

## 検証
`tests/master-multitrack-contract.test.mjs`：
1. 同じMIDI音高・40ms間隔の二音は最初の長さを変えない。
2. 5半音・50msの移動は従来どおりレガート延長する。
3. 7半音・50msの跳躍は短い息継ぎを保持し、7半音・20msの接近した跳躍は従来どおり接続する。
4. 110msの休止、ソース音符非破壊、ピアノ非影響を検査。

`tests/master-multitrack-browser.test.mjs`：既存の13秒・7秒持続音を含む模擬ハミングWAVに、12.2秒開始と12.62秒開始の同音高2音を追加。12.565〜12.595秒の空白が無音で、続く音が再発音されることを実Chromium PCM RMSで検査。既存の5秒・10秒分割、MUSIC-058/059位相、WAV長・休符・外部APIゼロの回帰検査も維持。
