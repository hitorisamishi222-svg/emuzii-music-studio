# MUSIC-092 — 独立した2曲のステムを合成するローカル基礎

2026-11-09 / 既存開発ブランチ `feature/vocal-recorder-v1` のみ。

## 完成した技術範囲
`integration/independent-stem-fusion.js` に、別々に作曲した演奏パート（例：曲Aの旋律と曲Bのベース）のPCMを、互いの素材を変更せずに1つのステレオ音声へ混ぜる独立した関数を追加。

- 2〜16トラック、各トラックに固有の名前、ゲイン（-60〜+12dB）、パン（左-1〜右+1）を設定。
- 24kHzを含む8〜48kHz、最大60秒の**同じ長さ・同じサンプルレート**のモノラルFloat32Array入力のみ許可。
- センターで左右各-3dBとなる等パワーパン、既定6dBのマスターヘッドルーム。
- トラック名の重複、NaN、欠損、サイズ不一致、範囲外のゲイン・パンを拒否。
- 合成ピークが1を超える場合は過負荷を明示し、WAV書出しを**拒否**。音を勝手に正規化したりクリップしたりしない。
- `createTailSafeWav` の既存の実装を再利用し、ステレオ16bit PCM WAVに2秒の完全無音を付加。
- 原音、各作曲ステム、SONG ID、TAKE、main、本番URLは編集しない。外部APIなし。

## テスト
`tests/independent-stem-fusion.test.mjs` と `.github/workflows/test-independent-stem-fusion.yml` により、2つの独立した合成音源を用いてステレオの左右差・再現性・原本不変・無音テール・オーバーロード拒否・不正入力拒否を検査。
