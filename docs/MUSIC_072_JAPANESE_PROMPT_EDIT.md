# MUSIC-072 — 日本語プロンプトで音楽編集（段階実装）

## コンセプト
ユーザーの「イントロを神秘的に」「歌声だけ少し前へ」「最後の8秒をフェードアウトして、2秒無音にして」を、**分析 → 編集案 → 試聴 → 承認 → 保存**につなげる。AIが勝手に「思い通りに編集できた」と宣言しない。

## 現在実装した最初の試作（開発ブランチのみ）
- `integration/japanese-outro-edit-plan.js`: 日本語の末尾フェード秒数と完全無音秒数を安全に解析し、編集案を生成する。
- `tools/outro-finisher.html`: 日本語入力欄と「指示を編集設定に変換」ボタン。設定を表示し、音声はユーザーがWAV生成ボタンを押すまで変更しない。
- 対応例：「最後の8秒をフェードアウトして、2秒無音にして」「フェードアウトを4秒、無音を3秒」。
- 実装外の指示（例：「ピアノを控えめに」「メロディを変更」）を検出したら編集全体の適用を拒否し、未対応を明示。指示の一部だけを黙って実行することはしない。
- セルフホスト/端末内の決定的な処理なので、外部AI・GPU起動・課金は不要。保存済みの原音は上書きしない。
- `tests/japanese-outro-edit-plan.test.mjs`：指示理解・数値境界・競合・未対応表現の拒否。
- `tests/outro-finisher-browser.test.mjs`：日本語から実際に変更された画面設定とWAV出力を検証する。
- 対応範囲は限定的。**自由文すべてに対応する音楽編集AIの完成ではない。**

## 段階的な拡張
1. **決定的なマスタリング操作**：音量、ステレオ幅、左右バランス、フェード、無音、区間指定、トラック・セクション選択を既存のエンジンへ安全に接続。
2. **パート単位の編集**：既存のマルチトラック/ステムがあるなら歌声・ピアノ・ベースなどを指定して音量や加工を調整。2ch完成音源しかない場合は分離品質に依存し、「声だけ」を保証しない。
3. **演奏・旋律編集**：MIDI・コード進行・編曲タイムライン・自然音などの制作素材があれば音符や楽器配置の変更案を生成し、A/B試聴。
4. **生成系の変更**：音源の欠落部分の補完、新規楽器・歌声の再生成は音楽生成モデル/適法な権限/費用確認/音質試験が必要。プロンプトだけで元の録音から任意の新しい表現が確実に作れるわけではない。

## 必須の保護
- 元音源・SONG ID・TAKE・制作履歴を保持し、バージョン別に新規出力。
- 理解できない指示・曖昧な対象・未対応の楽器操作は無断で実行しない。
- プロンプトは**編集計画の提案**で、元データ更新は明示操作のみ。
- プレビュー・A/B比較・Undo（変更履歴）・出力前後の波形数値と実際の音を確認。
- 既存GitHubリポジトリ/開発ブランチを維持。本番公開、外部API接続、GPU課金はユーザーの別途承認まで禁止。
