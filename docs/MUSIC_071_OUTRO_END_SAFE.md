# MUSIC-071 — アウトロ保護と末尾の完全無音（開発版）

## 目的
Sunoなどで作った音源を端末内で読み込み、元音源を一切上書きせず、新しい16-bit PCM WAVの末尾に2秒以上の完全無音を追加する。音楽や歌詞が途中で消えていた場合に、無音追加だけで修復できたと誤認させない。

## 追加した実装
- `integration/audio-tail-finisher.js`: 1〜2ch Float32 PCM → 16-bit WAV。既存サンプルを省略・切り詰めせず処理し、末尾へサンプル値0のPCMを追加。
- `analyzeAudioEnding()`: 元音源の最後250msの実効値を検査し、音が比較的大きく残っている可能性を警告。自動的な「歌詞完走」判定ではない。
- `tools/outro-finisher.html`: スマホ対応の端末内音源読み込み、無音長選択、任意フェード（既定OFF）、WAV保存・試聴。外部アップロードなし。
- `app-v10.3.2.html`: MASTER WAV書き出し付近に開発ツールへのリンクを追加。
- `tests/audio-tail-finisher.test.mjs`: PCM原本保護、RIFFヘッダ、追加無音の完全0、モノ/ステレオ、警告、任意フェード、入力拒否のテスト。
- `.github/workflows/test-outro-finisher.yml`: 関係ファイル変更時だけ上記ユニットテストを実行。

## 使用手順（開発ブランチをWebサーバーから閲覧する場合）
1. Studioの「完成WAVを書き出す」で保存する。またはSunoからWAVを用意する。
2. 「🌙 アウトロ・無音2秒仕上げ」を開き、音源を選択する。
3. 無音「2秒」、フェード「なし」を選ぶ。音源そのものを保持するため、フェードは必要なときだけ明示的に選択。
4. 新しいWAVを生成し、最後の歌詞・自然なアウトロ・無音を**人が実際に試聴**する。
5. 元の歌詞やアウトロが途切れていれば、先にSuno Extendなどで音源を補完する。今回のツールだけで復元することは不可能。

- Chromiumブラウザ実操作CI（WAV選択→デコード→保存→完全無音2秒＋途中切れ警告）: https://github.com/hitorisamishi222-svg/emuzii-music-studio/actions/runs/42382687670 — success。
- 初回ブラウザテストは、ChromiumのAudioContextが入力16kHzを44.1kHzへ変換する挙動をテスト側が考慮せず失敗。その後、出力WAVのサンプルレートを基準に検証する形へ修正し合格。
- ユニット検査およびChromiumでの基本的なファイル選択・変換・保存・末尾警告までは実証済み。iPhone/Android実機操作、実楽曲の末尾聴感評価、リリース統合は未検証。デコード時にブラウザのサンプルレートへ変換される場合があり、出力WAVのPCMバイト列は入力ファイルと一致しない。入力元ファイルは常に変更されない。
- ファイル容量は出力WAVのデータ部最大512MiB、1〜2ch、整数8k〜192kHz。ファイルデコードの対応形式はブラウザ依存。
- **元の音声・SONG ID・TAKE・保存DB・本番main・公開URLは変更していない。**
- 末尾に音が残った音源へ無音を足しても「急に切れた」音自体は直らないので、警告に従いExtendや編集が必要。
