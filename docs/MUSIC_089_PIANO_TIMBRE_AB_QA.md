# MUSIC-089 — 三重検証：実録音ピアノのスペクトル連続性＋聴感A/B（2026-11-09）

## 三重思考での判断

### ① 現状確認
MUSIC-088では録音ピアノの強弱64〜96、各C3/C4/C5の33段階でRMS音量の逆戻りを測定し、減衰のみの補正で検出基準（-0.25dB未満）に該当する箇所を0へ改善した。ただし **RMSが滑らかでも、音色が自然とは限らない**。2つの録音を重ねると、振幅ゲインを調整しても周波数ごとに打ち消しが起き得る。

### ② 実装
- `integration/piano-timbre-sweep-audit.js`: スペクトル形状の差を連続した強弱の各段階で解析。2048点のHann窓FFT、60Hz〜最大9.5kHz（Nyquistを超えない）の24個の対数周波数帯を使用。音符開始から0.10秒後の短い窓を解析する。
- 各強弱のスペクトル重心（Hz）、高域（2kHz以上）の比率、隣接段階の正規化スペクトル形状差（0〜1）を記録。**0.20以上は聴感確認の目安となる警戒値**。ここで超過しなくても音色が良い、位相干渉がない、という意味ではない。
- `tests/piano-timbre-sweep-audit.test.mjs`: 同じ音程の波形に対する再現性、周波数の急変検出、入力改変防止、NaN/音源不足の拒否、既存6音色スコアとの接続を検証。
- `tests/real-piano-six-sample-browser.test.mjs`: 固定されたMeta Open Sound / Meta Pianoの実録音CC0-1.0の6ファイルをSHA-256でチェックしてから、ChromiumでC3/C4/C5の各33段階をレンダリング。補正なし・レベル補正後の両方の音色変化データを`velocity-64-96-timbre-audit.json`へ保存。
- `tools/piano-listening-qa.html`: ブラウザ内で**比較A/B WAVを選択→同じ再生位置で切替→人間が強弱・音色・違和感の有無を判断→JSONで保存**する小さな検証画面。音声や評価は外部送信しない。
- 既存開発スタジオの画面にA/B聴感確認ページへのリンクを追加。公開中の本番メインは変更せず、開発ブランチ限定。
- ブラウザQAでは録音ピアノ由来の生成WAVを2つ読み込み、切替とレビューJSON保存まで操作を検証。**テストコードが入力した「Bが良い」は実際の試聴評価ではない**。

### ③ 実録音による仕上がりチェック
実録音素材の出典とライセンスの固定方法は`docs/MUSIC_084_RECORDED_PIANO_MULTISAMPLE.md`を参照。解析単位はC3/C4/C5の原基準音、ベロシティ64〜96（33段階）。

| 基準音 | 補正前の最大隣接スペクトル形状差 | 補正後の最大差 | 警戒値0.20を超えた段階 |
| --- | ---: | ---: | ---: |
| C3 | 0.0452 | 0.0452 | 0 |
| C4 | 0.0102 | 0.0102 | 0 |
| C5 | 0.0335 | 0.0335 | 0 |

*重要：スペクトル変化は少しずつ連続しても、弱音と強音の音色自体は大きく異なり得る。さらにFFTの窓は0.10秒付近の短時間だけなので、アタック、長い余韻、位相干渉による局所的な音質の劣化がないと保証しない。*

- 音量だけを減衰する補正では、**強弱を跨ぐ周波数形状の差はほとんど変化しなかった**。音量補正で音色の変化まで改善したとは主張しない。
- 耳によるA/B評価、実機のiPhone/Android検証、48kHz/24bitの元録音への拡張は**未実施**。
- GitHub Actions artifactにWAVと周波数診断レポートを保存し、期限内に取得できる。今後の実耳検証で音楽的な判断を行う。
- 開発版のリンク：`tools/piano-listening-qa.html`。ソースの改変は未実施、本番配信・音楽品質の正式合格は保留。
